# ⚖️ Sindh High Court — Cause List Analytics Dashboard

A Streamlit application for exploring daily cause-list data from the Sindh High Court — case volumes, judge workloads, court sections, advocates, and full case search.

## Features

- **Overview** — high-level KPIs and case volume trends
- **Daily Cause List** — browse cases scheduled per day
- **Judge Analysis** — workload distribution across judges
- **Court Infrastructure** — case breakdown by court section
- **Lawyer Intelligence** — top advocates (petitioner/respondent side), lawyer search
- **Case Search** — search by case number, party name, advocate, or judge

## Project Structure

```
Sindh/
├── dashboard/
│   └── app.py              # Main Streamlit dashboard
└── cause_lists/
    └── Sindh_Cause_List_*.xlsx   # Daily cause list data files
```

> **Note:** `app.py` expects the `cause_lists` folder to sit **one level above** the `dashboard` folder (i.e. as a sibling). This matches the automation script's output location. Keep this structure intact when deploying.

## Requirements

- Python 3.9+
- See `requirements.txt` for package dependencies

## Running Locally

```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
```

The app will open at `http://localhost:8501`.

## Data

Data files must follow the naming pattern `Sindh_Cause_List_YYYY-MM-DD.xlsx` (or similar) and be placed inside the `cause_lists/` folder. These are generated by the companion automation script (`sindh_causelist_auto.py`), which downloads, parses, and exports the daily cause list as Excel files.

## Notes on Deployment

This app reads local Excel files rather than a database. When deploying (e.g. to Streamlit Community Cloud), make sure the `cause_lists/` folder and its data files are included in the repository, or that data is synced into the deployed environment through another means (e.g. scheduled commits).
